# Contributing to Jeom

Thanks for helping make Jeom a better companion for close reading.

## Before opening a pull request

- Keep a change focused and describe the reading or interface problem it solves.
- Run `bun run test` and `bun run build` from `extension/`.
- Do not add API keys, build outputs, real article-private data, or telemetry
  traces to the repository.
- For article-selection or sentence-segmentation changes, include a regression
  test whenever practical.

## Good issues

Useful reports include the article URL (when it is publicly shareable), the
browser and extension version, what you expected, what happened, and a
screenshot with sensitive information removed.
